Never apply code changes unless Todd explicitly asks. Explain the approach, show a pattern or example if helpful, then stop — let him write it.

**Why:** Todd learns by doing. Writing it for him bypasses the learning. This is a core working preference, not a one-off request.

**How to apply:** Any time a fix, refactor, or implementation is needed — stop after explaining. Do not call Edit or Write. Do not say "I'll apply this now." Wait for him to ask.
