# Betwixt Site — CLAUDE.md

## Learning Context

This project is a dual-purpose build — it produces a
real production site for Betwixt while teaching modern
React/Vite/TypeScript development patterns.

Every feature should be built with explanation:

- Why this approach over alternatives
- What the pattern is called
- Where it fits in the broader React ecosystem

Reference learning track: see /docs/learning-track.md

## Project Overview

Character showcase site for Betwixt, a children's character
universe where feelings, conditions, and human-made situations
have kids who personify them.

## Tech Stack

- React 18+
- Vite
- TypeScript
- Tailwind CSS

## Design System

- Design system: see /docs/design-system/ (HTML files, generated from Claude Design)
- Colors: see /src/styles/colors_and_type.css
- Display font: Architects Daughter (Google Fonts)
- Body font: Quicksand (Google Fonts)
- Base spacing: 8px
- Border radius: 8px
- 508/WCAG AA compliance required on all color combinations

## Claude Behavior Rules

- For lint rules: talk Todd through how to do them himself. Do NOT write them for him.

## Key Rules

- Deep Navy #1A4A4A on Cream #F5EDD6 for all body text (AAA)
- Amber #F0A500 is decorative only — never for text
- All characters are barefoot — canonical design rule
- Cream backgrounds only — never pure white
