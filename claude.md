# Betwixt Site — CLAUDE.md

## Project Overview
Character showcase site for Betwixt, a children's character 
universe where feelings, conditions, and human-made situations 
have kids who personify them.

## Tech Stack
- React 18+
- Vite
- TypeScript
- Tailwind CSS

## Design System
- Style guide: see /docs/style-guide.md
- Colors: see /src/styles/colors_and_type.css
- Display font: Architects Daughter (Google Fonts)
- Body font: Quicksand (Google Fonts)
- Base spacing: 8px
- Border radius: 8px
- 508/WCAG AA compliance required on all color combinations

## Key Rules
- Deep Navy #1A4A4A on Cream #F5EDD6 for all body text (AAA)
- Amber #F0A500 is decorative only — never for text
- All characters are barefoot — canonical design rule
- Cream backgrounds only — never pure white
